# Hatena Blog MCP Server

はてなブログのAtomPub APIを利用してブログ記事を参照するMCP (Model Context Protocol) サーバーです。

## 概要

このMCPサーバーは、はてなブログの記事データに対してAIアシスタントがアクセスできるようにするためのツールです。AtomPub APIを使用してブログの記事、カテゴリ、メタデータを取得できます。

## 主な機能

- **ブログエントリの一覧取得**: ページネーション付きでブログ記事を取得
- **特定のエントリの詳細取得**: エントリIDを指定して詳細情報を取得
- **エントリの検索**: タイトルや本文による検索機能
- **カテゴリ一覧の取得**: ブログで使用されているカテゴリの一覧を取得

## アーキテクチャ

```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   AI Assistant  │    │  MCP Server     │    │  Hatena Blog    │
│                 │◄──►│                 │◄──►│  AtomPub API    │
│  (Claude etc.)  │    │  hatena-blog-   │    │                 │
└─────────────────┘    │      mcp        │    └─────────────────┘
                       └─────────────────┘
```

## 動作環境

- Python 3.10以上
- MCPプロトコル対応のAIアシスタント
